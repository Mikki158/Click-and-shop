# Click-and-shop

## Обзор
Этот проект представляет собой приложение маркетплейс, созданное с использованием архитектуры микросервисов. Оно предназначено для поддержки таких функций, как аутентификация пользователей, управление товарами и работа с продавцами, обеспечивая масштабируемость, модульность и гибкость. Приложение включает в себя несколько служб, которые взаимодействуют друг с другом через REST API.

---

## Функции

### 1. **Сервис аутентификации**
   - Обрабатывает регистрацию и вход в систему пользователей через Telegram.
   - Управляет генерацией и проверкой токенов JWT.
   - Обеспечивает централизованную аутентификацию для всех микросервисов.

### 2. **Сервис товаров**
   - Управляет созданием, обновлением и удалением продуктов.
   - Поддерживает список продуктов с возможностью фильтрации и сортировки.
   - Позволяет продавцам управлять своими собственными продуктами.

### 3. **Сервис продавцов**
   - Позволяет продавцам управлять своими профилями и брендами.
   - Предоставляет продавцам инструменты для отслеживания и анализа эффективности своей продукции.

## Стек технологий

### Backend:
- **Java** (Spring Boot)
- **Spring Security**
- **Spring Data JPA**
- **Hibernate**
- **Nginx**

### DataBase:
- **PostgreSQL**

### Инструменты и библиотеки:
- **ModelMapper** для преобразования DTO
- **io.jsonwebtoken** для обработки JWT
- **Spring RestTemplate** для межсервисного взаимодействия

### Контейнеризация:
- **Docker** для развертывания служб
